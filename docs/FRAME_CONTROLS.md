# Steam Frame controls

The default Steam Frame profile keeps the game's VR actions and routes them to
the buttons printed on the Frame controllers. Controls change by context: some
game actions only work during gameplay, and menu actions only work in menus.

## Gameplay

| Frame control | Action |
| --- | --- |
| Left stick | Move |
| Left stick click | Sneak |
| Right stick | Turn; hold downward to open the quick wheel, move the right hand to an item and release to use it |
| Right stick click | V.A.T.S. |
| Right trigger | Attack |
| Left trigger | Manual magazine handling: take the magazine out, reach behind the left shoulder for a new one, then guide it into the weapon |
| Right grip | Grab; holster/draw near the right hip or right shoulder, depending on weapon; switch the Pip-Boy light near the left forearm |
| Left grip | Support the weapon with both hands; a free hand can grab world objects |
| A | Activate |
| B | Jump |
| X | Reload weapons without manual magazine handling; cycle ammunition while holding a magazine in the left hand; activate a prompt shown at the left hand |
| Y, tap | Wait |
| Y, hold | Open the pause menu |

Look at the left forearm to open the Pip-Boy.

## Menus

Point with either controller's laser. Click either trigger or press A to select;
press B to go back. The left stick navigates, the right stick scrolls or performs
secondary menu actions, X is alternate, and Y is option. Use the left grip for
the previous tab or the right grip for the next tab. In the Pip-Boy inventory,
hold the right grip (the game's RB input) and use the left stick to assign a
highlighted item to a hotkey slot.

## Alternate profile

The Oculus Touch profile remains available as a fallback. Its face-button labels
and hand placement differ from the Steam Frame profile.
